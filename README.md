# 破阵 · Ayaya Breach

回合制解谜游戏。在棋盘上移动角色、推动方块，触发开关后到达出口。

## 怎么玩

1. 操作小人，在铺有地砖的区域移动。点相邻格或按方向键移动；点小人或按空格，原地等待一步。
2. 触发本局所有 A / B 开关，再走到出口。
3. 红线预告下一步的射击。炮台下方三个点依次表示未来三步：实心射击，空心停火。
4. 木箱可以推动，也可以挡住火线；墙块不能推动。没有地砖的外围留白不属于可走区域。
5. 被击中、推错或想换思路，都可以撤回。没有计时器，也没有步数上限。

结算顺序固定：**移动 / 推方块 → 触发开关并关闭对应炮台 → 开火 → 判断是否到达出口**。走向墙或推不动方块，不消耗步数。开关和掩体可以改变本步火力，所以红线按当前布局预览，邻格的叉号表示实际走过去会中炮。

`↑ ↓ ← →` / WASD 移动，`Space` 等待，`Z` / `Backspace` 撤回，`R` 重来。菜单内暂停游戏快捷键；`Esc` 关闭菜单。手机可以点按或在棋盘上滑动。

## 关卡

| 阶段 | 关卡                                   | 最短步数      |
| ---- | -------------------------------------- | ------------- |
| 基础 | 交替射击、连续通行、两个开关           | 8、11、15     |
| 进阶 | 推动掩体、移开方块、双向射击、保留退路 | 8、13、16、17 |
| 挑战 | 两个方块、开关顺序、综合关卡           | 23、23、28    |

全部关卡可以直接挑战。难度来自开关顺序、炮台周期、掩体位置与回程安排。最短步数是优化目标，不是通关门槛；每关的标注都由完整状态空间的广度优先搜索验证。

点按炮台可依次切换两步后、三步后、下一步的火力，也可在“更多”中选择。预览不推进棋局，按当前掩体和开关计算；实际操作后自动回到下一步。炮台下方三个点始终表示实际回合之后的三步，不随预览偏移。键盘聚焦炮台后可用 Enter 或空格切换预览。每关另有一条可展开的思路提示。

## 数据与前端

- 页面紧凑排列标题、棋盘和一行关卡 / 步数 / 操作。通关后，等待原位变成下一关，结果以一行文字显示。预留反馈高度，避免操作时棋盘上下移动。
- 选关和设置使用同色背景，隐藏底下的棋盘，不显示遮罩卡片。重来、提示、主题和预览选项放在“更多”中，规则按需展开；初次移动和推方块时各显示一句说明。
- 浅色 / 深色两种主题，文字按钮、同一像素网格绘制的人物和物件。交错地砖标明可走区域，无格子描边，外围墙不绘制；墙、木箱、开关、门与火线均有独立的外观。原生 DOM 棋盘与 SVG 炮线，没有外部字体、账号、追踪或运行时依赖。
- 只使用浏览器 `localStorage` 保存当前关卡、操作记录、个人最佳和主题，刷新可继续，撤回记录也会恢复。
- 损坏或不可用的存储不会阻止游玩。单次操作记录最多保存 4096 步，超过后仍可继续游玩并保存通关成绩，页面会说明当前棋局无法续存。
- v4 使用独立的存储键 `ayaya-breach-v4`，保留旧版存储，不把旧版塔防分数映射成新谜题成绩。
- 只在交互时更新界面，没有持续运行的动画循环。支持减少动态效果、键盘焦点、状态朗读与菜单焦点约束。

## 本地开发与验证

需要 Node.js 22：

```bash
npm ci
npm run dev
```

格式、规则测试、类型检查与生产构建：

```bash
npm run validate
```

Chromium 桌面和 iPhone WebKit 浏览器回归测试：

```bash
npx playwright install chromium webkit
npm run test:e2e
```

浏览器测试会启动独立的生产预览服务，验证十局真实操作通关、续局、撤回、推掩体、预览、主题、菜单、触控与多种屏幕尺寸。GitHub Actions 会在 Pages 部署前执行两套检查。

## 代码结构

- `src/engine.ts`：无副作用的规则与火线计算。
- `src/levels.ts`：十局固定地图与逐关提示。
- `src/solver.ts`：关卡验证器，仅被测试使用，不进入游戏包。
- `src/storage.ts`：校验、保存和回放当前棋局。
- `src/main.ts` / `src/style.css`：交互与响应式界面。
- `src/sprites.ts`：角色、方块、炮台、开关和出口的 SVG 图形。
- `src/*.test.ts` / `e2e/game.spec.ts`：规则、存储与浏览器回归。

静态部署路径沿用 `/AyayaGame_1/`，无需后端。v4 改造说明见 [审查记录](docs/REVIEW.md)。
