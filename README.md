# Ayaya Breach Protocol · 反向塔防

一款 browser-only 的极简反向塔防游戏。操作只有两个：拖动路线、安排出兵顺序。

## 玩法

- 拖动三个路标，从修复、加速、停火三枚中继中任选两枚。
- 路线总长度不能超过 1.28；红色火力上限会从 58% 逐轮收紧到 52%。
- 每轮只能购买 2–4 批单位，购买顺序就是部署顺序。
- 史莱姆负责消耗火力，疾行兽快速穿越，铁甲兽承担核心伤害。
- 防线会沿上一轮路线重新布置；重复路径会使防御塔伤害提高 80%。
- 进化在回合结束时自动获得，不需要额外选择。
- 四回合内将核心完整度从 36 降至 0。

## v3.6 · Read the Defense

- 防线提示现在直接说明目标逻辑：脉冲追前排、迟滞盯高速、穿甲轰密集，让出兵顺序真正可推理。
- 回合结算不再复述数字，而是指出失败位置并给出下一轮可执行的反制方向。
- 红路上限逐轮从 58% 收紧到 52%；若极端塔位没有标准解，上限只放宽到刚好存在可行路线。
- 缩小塔的射程并提高命中伤害：走线更能创造安全区，但一次错误更致命。
- 史莱姆海成功后会触发真实的范围火力反制，不再依赖已经删除的旧阵型系统。
- 修复“干扰回声”进化，让停火中继确实延长 1.2 秒；清除旧指令、旧阵型等无效规则。
- 全部常用文字提升到 12–15px，单位数量与价格合并到同一信息组，小屏不再隐藏价格。
- 新增多种历史路线与四类自适应防线的可解性验证，确保高难度仍然公平。

游戏数据只保存在浏览器本地，不需要账号，也不会上传数据。

## 本地开发

需要 Node.js 22：

```bash
npm install
npm run dev
```

完整验证：

```bash
npm run validate
```
