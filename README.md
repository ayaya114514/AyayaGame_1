# Ayaya Breach Protocol · 反向塔防

一款 browser-only 的极简反向塔防游戏。操作只有两个：拖动路线、安排出兵顺序。

## 玩法

- 拖动三个路标，从修复、加速、停火三枚中继中任选两枚。
- 路线总长度不能超过 1.28；火力暴露上限会从 58% 逐轮收紧到 52%。
- 每轮只能购买 2–4 批单位，购买顺序就是部署顺序。
- 史莱姆负责消耗火力，疾行兽快速穿越，铁甲兽承担核心伤害。
- 防御塔连射 2–4 次后过载；外圈亮点就是它的剩余连射。
- 防线会沿上一轮路线重新布置；重复路径会使防御塔伤害提高 80%。
- 进化会自动针对本轮暴露的弱点，不需要额外选择。
- 四回合内将核心完整度从 36 降至 0。

## v3.7 · Break the Rhythm

- 三类塔拥有不同的连射长度和过载窗口；伤害同步提高，错误顺序更致命，骗空火力后的突破也更明显。
- 每座塔的剩余连射直接画在外圈，战斗反馈不再依赖小字解释。
- 上一轮路线会留下虚线残影；当新路线过于相似时，直接显示重复伤害倍率。
- 随机进化改为应激进化：失败时修复暴露的弱点，成功时放大主力或三中继路线的优势。
- 结算用“先损失”替代重复的部署数，直接指出出兵顺序的首个破绽。
- 路线指标改为紧凑的同行读法，减小底部控制区；“下一回合”恢复可读文字，移动端不再只显示一枚箭头。
- 核心路线预算、逐轮火力上限和极端塔位的可解性保护全部保留。

游戏数据只保存在浏览器本地，不需要账号，也不会上传数据。

## 本地开发

需要 Node.js 22：

```bash
npm install
npm run dev
```

完整验证：

```bash
npm run validate
```
