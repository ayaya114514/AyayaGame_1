# Breach Protocol · 反向塔防

一款 browser-only 的反向塔防策略游戏。这次玩家扮演怪物：设计路线、购买并排列怪物批次，在五回合内突破会学习玩家打法的 AI 防线。

## 玩法

- 拖拽三个路标或选择路线预设，绕开 AI 防御塔射界。
- 组合史莱姆群、疾行兽与铁甲兽，每种单位拥有不同数量、速度、生命与突破伤害。
- 用紧密、标准或分批节奏控制各批次间隔。
- 让路线穿过再生、跃迁或干扰信标，在危险绕行与强力临时增益之间取舍。
- 每波可释放一次 EMP，让全部防御塔短暂离线；进化后还可延长持续时间。
- 每回合从三个进化中选择一个，永久强化数量、速度、护甲、经济或主动能力。
- AI 会针对高速、重甲、密集虫群和重复路线调整塔组，并显示可以反制它的战术提示。
- 在最多五回合内将 AI 核心完整度从 30 降至 0。

## v1.1 · Adaptive Evolution

- 新增 7 种永久进化，并保证同一局内不重复出现。
- 新增每回合随机战场信标和实时 Canvas 反馈。
- 新增单波主动指令与 `E` 键快捷操作。
- AI 新增集群清除与路径封锁协议，重复打法会遭遇更强针对。

游戏数据只保存在浏览器本地，不需要账号，也不会上传数据。

## 本地开发

需要 Node.js 22：

```bash
npm install
npm run dev
```

完整验证：

```bash
npm run validate
```
