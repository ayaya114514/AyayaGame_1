# Ayaya Breach Protocol · 反向塔防

一款 browser-only 的反向塔防策略游戏。玩家需要在五回合内接入战术中继、设计突破路线，并用出兵顺序和主动指令骗过会学习的 AI 防线。

## 玩法

- 每条路线必须接入至少一个中继；一个中继只能解除一半核心护盾，接入两个才能造成完整伤害。
- AI 会沿上一条路线重新布防，并针对上一轮的兵种与部署节奏选择迟滞、穿甲、集群清除或路径封锁。
- 重复路线会让防御塔伤害提高 30%，要求玩家持续改变解法，而不是复用一次成功走线。
- 史莱姆群、疾行兽与铁甲兽承担不同职责；购买顺序决定谁先骗出炮击、谁抢占中继、谁完成核心突破。
- 紧密、标准和分批节奏拥有明确 matchup：分别克制穿甲、迟滞与范围清除，也可能被对应防线惩罚。
- 每波从静默、冲刺和再生中选择一项主动指令，并在战斗中判断释放时机。
- 每回合三选一永久进化，但资源和编队上限迫使玩家持续做取舍。
- 在最多五回合内将 AI 核心完整度从 30 降至 0。

## v2.0 · Counterplay

- 中继成为路线的硬目标，不再允许任意画线直接开打。
- AI 从读取当前选择改为学习上一轮行为，玩家可以观察、预测并反制。
- 加入路线相似度、明确的重复惩罚、节奏克制和三种主动指令。
- 将三栏仪表盘式界面重构为战场 + 计划面板，去掉扫描线、氛围光和伪终端装饰。

游戏数据只保存在浏览器本地，不需要账号，也不会上传数据。

## 本地开发

需要 Node.js 22：

```bash
npm install
npm run dev
```

完整验证：

```bash
npm run validate
```
