# Ayaya Breach Protocol · 反向塔防

一款 browser-only 的极简反向塔防游戏。操作只有两个：拖动路线、安排出兵顺序。

## 玩法

- 拖动三个路标，让路线实际经过两个中继。
- 路线总长度不能超过 1.35；处于防御塔射程内的路段会直接变红。
- 每轮只能购买 2–4 批单位，购买顺序就是部署顺序。
- 史莱姆负责消耗火力，疾行兽快速穿越，铁甲兽承担核心伤害。
- 防线会沿上一轮路线重新布置；重复路径会使防御塔伤害提高 60%。
- 进化在回合结束时自动获得，不需要额外选择。
- 四回合内将核心完整度从 32 降至 0。

## v3.2 · Living Battlefield

- 删除路线预设、点击接入中继、部署节奏、主动指令和手动进化选择。
- 取消顶部栏、地图卡片和底部工具栏，让所有操作直接生长在全屏战场上。
- 单位、炮塔、中继、队列与按钮使用不规则生物轮廓，避免仪表盘式布局。
- 加入双中继、路线预算、2–4 批编队限制和更强的重复路线惩罚。
- 将塔的威胁直接编码到路线颜色中，减少阅读，增加空间判断。

游戏数据只保存在浏览器本地，不需要账号，也不会上传数据。

## 本地开发

需要 Node.js 22：

```bash
npm install
npm run dev
```

完整验证：

```bash
npm run validate
```
