# Ayaya Breach Protocol · 反向塔防

一款 browser-only 的极简反向塔防游戏。操作只有两个：拖动路线、安排出兵顺序。

## 玩法

- 拖动三个路标，从修复、加速、停火三枚中继中任选两枚。
- 路线总长度不能超过 1.28，红色火力路段不能超过 58%。
- 每轮只能购买 2–4 批单位，购买顺序就是部署顺序。
- 史莱姆负责消耗火力，疾行兽快速穿越，铁甲兽承担核心伤害。
- 防线会沿上一轮路线重新布置；重复路径会使防御塔伤害提高 80%。
- 进化在回合结束时自动获得，不需要额外选择。
- 四回合内将核心完整度从 36 降至 0。

## v3.5 · Two Signals, One Route

- 三选二中继把“必须经过”改成路线取舍：修复适合重装，加速适合突进，停火适合穿越重叠射界。
- 红路覆盖首次成为硬性出发条件，不能再无视塔位随便连线。
- 底部路线信息压缩为三个大数字：中继、红路、长度；删除进度条、重复说明和常驻进化列表。
- 顶部指引从三层文字缩成一个动作标题和一句原因，只显示当前阻碍。
- 中继直接使用三种高对比颜色，并用光环与勾号表示已接通，减少来回阅读。
- 统一重复路线判定；旧路线仍可冒险使用，但全部塔伤提高 80%。
- 每回合都通过自动测试确认存在满足 1.28 长度和 58% 火力上限的双中继路线。

游戏数据只保存在浏览器本地，不需要账号，也不会上传数据。

## 本地开发

需要 Node.js 22：

```bash
npm install
npm run dev
```

完整验证：

```bash
npm run validate
```
